## 3. Typography

### Primary Typeface: Slalom Sans
**Use for**: All digital and print applications (except PowerPoint)

| Weight | Use Case |
|--------|----------|
| **Light** | Large headlines, elegant moments |
| **Regular** | Body text, paragraphs |
| **Medium** | Subheadings, emphasis |
| **Bold** | Headlines, strong emphasis |
| **Black** | Extra impact, large display |

### Supporting Typeface: Lora
**Use for**: Print/editorial pieces only (long-form reading)

| Weight | Use Case |
|--------|----------|
| **Regular** | Body text in print materials |
| **Italic** | Emphasis, quotes |
| **Bold** | Subheadings in print |

### PowerPoint Typeface: Avenir Next LT Pro
**Use for**: PowerPoint presentations only

| Weight | Use Case |
|--------|----------|
| **Regular** | Body text |
| **Demi** | Subheadings |
| **Bold** | Headlines |

### Typography Best Practices
- **Hierarchy**: Establish clear visual hierarchy with size and weight
- **Line spacing**: 1.5x for body text, tighter for headlines
- **Line length**: 50-75 characters for optimal readability
- **Alignment**: Left-aligned for body text, centered for headlines when appropriate
- **Sentence case**: Preferred over title case for modern, approachable feel

## 4. Logo Usage

### Primary Logo
- Slalom wordmark with blue color
- Minimum size: **0.125" / 9px** height
- Clear space: Equal to height of "S" on all sides
- Always use provided artwork files (never recreate)

### Logo Variations
1. **Full color** (primary) - Slalom Blue on white/light backgrounds
2. **Reverse** - White on dark backgrounds or photography
3. **Black** - Single-color applications
4. **White** - Reversed applications

### Logo Don'ts
- ❌ Don't stretch or distort
- ❌ Don't change colors or add effects
- ❌ Don't rotate or skew
- ❌ Don't place on busy backgrounds without sufficient contrast
- ❌ Don't use outdated logo versions

### Sub-brands and Capabilities
Each capability may have its own logo lockup. Use approved lockups from the Creative Library. Follow same size and clear space rules as primary logo.

## 5. Photography Style

### Photo Characteristics
- **Authentic**: Real moments, genuine emotions, candid shots
- **Bright**: Well-lit, optimistic, clear
- **Diverse**: Inclusive representation across all dimensions
- **Joyful**: Positive energy, collaboration, human connection
- **Professional**: High-quality, in-focus, well-composed

### Photo Subjects
✅ **Do**:
- Show real people in genuine work scenarios
- Capture diverse teams collaborating
- Include technology naturally (not forced)
- Show bright, modern office environments
- Feature close-up portraits with eye contact

❌ **Don't**:
- Use obvious stock photography poses
- Show outdated technology or settings
- Use overly staged or stiff compositions
- Feature low-quality or poorly lit images
- Show people staring awkwardly at cameras

### Photo Treatment
- No filters or heavy color grading
- Maintain natural skin tones
- Keep images bright but not overexposed
- Use shallow depth of field to create focus
- Crop thoughtfully to emphasize subjects

## 6. Graphic Elements

### Slalom Dot Pattern
- Proprietary pattern element using circular dots
- Available in various configurations and densities
- Use to add texture and brand recognition
- Never modify spacing or shape of dots

### Lines and Shapes
- **Clean, geometric shapes**: Circles, rectangles, simple forms
- **Vibrant accent colors**: Use supporting palette colors
- **Purpose**: Frame content, guide eye, add energy
- **Don't**: Overuse or create visual clutter

### Gradients
- Subtle gradients acceptable with brand colors
- Must maintain accessibility and readability
- Avoid harsh transitions

### Iconography
- Simple, geometric line icons
- 2-3pt stroke weight
- Use brand colors
- Maintain consistent style across icon sets
- Available in Creative Library

## 7. Writing and Messaging

### Voice and Tone
- **Conversational**: Write like you speak, avoid jargon
- **Confident**: Clear and assured, not arrogant
- **Optimistic**: Solutions-focused, forward-thinking
- **Human**: Warm, authentic, relatable

### Writing Guidelines
- **Sentence case**: Use sentence case for headlines and CTAs (not Title Case)
- **Active voice**: "We help clients transform" not "Clients are helped to transform"
- **Concise**: Respect reader's time, get to the point
- **Inclusive**: Use "they/them" as singular pronouns, avoid gendered language
- **Em dashes**: Use em dashes—like this—for emphasis (not hyphens or en dashes)

### Editorial Style
- Follow **Chicago Manual of Style** (17th edition)
- Use **Oxford comma**: "strategy, design, and technology"
- Spell out numbers one through nine, use numerals for 10+
- Use % symbol with numerals (not "percent")

### Common Terms
- **Slalom** (never "SLALOM" or "slalom" in body text)
- **Build is a capability** (when referring to Slalom Build)
- **Client** (not customer)
- **People** (not resources or headcount)

## 9. PowerPoint and Presentations

### Presentation Design
- Use **Avenir Next LT Pro** typeface (PowerPoint only)
- Apply branded templates from Creative Library
- Use brand colors consistently
- Include Slalom logo on title and closing slides

### Slide Layout Principles
- **One idea per slide**: Keep it focused
- **Visual hierarchy**: Large headlines, supporting body text
- **White space**: Don't overcrowd slides
- **Data visualization**: Clean charts with brand colors
- **Photography**: Use brand-approved photography when applicable

### Presentation Don'ts
- ❌ Don't use default PowerPoint templates
- ❌ Don't use clipart or low-quality images
- ❌ Don't use multiple typefaces
- ❌ Don't add excessive animation
- ❌ Don't ignore accessibility (contrast, font size)

## 10. Accessibility Standards

### WCAG 2.1 AA Requirements
Slalom commits to **WCAG 2.1 Level AA** compliance for all digital properties.

### Key Accessibility Rules
1. **Color contrast**: Minimum 4.5:1 for normal text, 3:1 for large text
2. **Text alternatives**: Provide alt text for all images
3. **Keyboard navigation**: All functions accessible via keyboard
4. **Readable fonts**: Minimum 16px for body text
5. **Clear labels**: Descriptive link text (not "click here")
6. **Captions**: Provide captions for video content
7. **Focus indicators**: Visible focus states for interactive elements

### Testing Accessibility
- Use automated tools (WAVE, axe DevTools)
- Test with screen readers
- Verify keyboard navigation
- Check color contrast ratios
